# Práctica 06 - Desarrollo Móvil Integral

En este directorio se encuentra el desarrollo correspondiente a la **Práctica 06** de la materia de Desarrollo Móvil Integral:

## Contenido

- 🎬 **[Cinemapedia](./cinemapedia/README.md)**: Aplicación cinematográfica completa con Clean Architecture, consumo de The Movie DB API, gestión de estado con Riverpod, enrutamiento con GoRouter, base de datos local Isar Community (Favoritos), reproductor de trailers de YouTube, soporte multi-idioma (5 idiomas), nuevo logotipo e identidad visual vectorial, pantalla de splash animada y carrusel interactivo con navegación por flechas de uno y doble clic.
- 📐 **[Arquitectura de Cinemapedia](./Arquitectura/Arquitectura_de_Cinemapedia.html)**: Diagrama interactivo y visualizaciones claras y oscuras de la arquitectura de la aplicación.
